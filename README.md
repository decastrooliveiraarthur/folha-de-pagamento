# Folha de Pagamento

Programa em Java que cadastra funcionários, calcula o salário de cada um e lista a folha de pagamento completa. Projeto feito para a faculdade.

## O que faz

Permite cadastrar três tipos de funcionário, cada um com uma forma diferente de calcular o salário:

- Funcionário comum (salário fixo)
- Comissionado (salário por vendas + percentual)
- Funcionário por produção (salário por quantidade produzida)

No final, mostra a lista de todos os funcionários cadastrados com seus salários.

## Como executar

1. Abra o projeto no IntelliJ IDEA.
2. Execute a classe `Main.java`.
3. Siga o menu no console.

## Tecnologia

Java
